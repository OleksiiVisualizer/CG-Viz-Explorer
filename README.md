**CG-Viz Explorer** is a modern, blazing-fast, and user-friendly asset manager for 3D models, materials, HDRI, and textures, designed specifically for CG artists and architects.

### 🇬🇧 What's New (Changelog):
* Full two-way integration with Autodesk 3ds Max (fast model import and `.mat` material assignment).
* Smart thumbnail caching for heavy assets (HDRI, IES, 3ds Max files) for instant gallery loading.
* Built-in Seamless Texture Generator and PBR map creation (Normal, Displacement, Reflect).
* Interactive overlay for viewing 360 panoramas, IES profiles, media, and PDF documents.
* Dark and Light UI themes.
* Multi-viewport support (up to 4 panes simultaneously) with independent navigation and Drag-and-Drop capabilities.
