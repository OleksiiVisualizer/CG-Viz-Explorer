# English Version 🇬🇧

## 🌟 About the Project
**CG-Viz Explorer** is an ultimate tool for cataloging, managing, and utilizing your 3D library. From 3D models and materials to scripts and heavy HDRI maps — everything is structured and accessible in just a few clicks.

## ✨ Key Features

- **📦 Instant Cataloging:** Seamlessly browse 3D models (.max, .fbx, .obj, .blend), materials, IES lights, textures, videos, and audio files.
- **🔌 Deep 3ds Max Integration:** Drag-and-Drop assets directly into the scene, flexible import settings, script bridge (Listener), auto-assignment, and automatic material preview rendering (.mat).
- **🏷️ Smart Tag System:** Hierarchical tag tree, Favorites, and instant global database search.
- **👁️ Premium Viewers & Players:** Fullscreen HDRI/EXR viewer with 360° mode and exposure control, built-in audio and video players with playback speed adjustments.
- **🛠️ Built-in CG Tools:**
  - Seamless texture generator (with an interactive 3D sphere preview).
  - PBR map generator (Normal, Bump, Reflect, Displace).
  - Optimizer and resizer for heavy textures and HDRIs.
  - Batch image format converter.

## 🚀 How to Install and Run (.exe)

This software is distributed as a ready-to-use standalone `.exe` file (Portable). You don't need to install Python or any additional libraries.

1. Go to the **[Releases](../../releases)** section on this GitHub page.
2. Download the latest archive (for example, `CG-Viz_Explorer_v1.0.zip`).
3. Extract the archive to any convenient folder (e.g., `D:\CG-Viz Explorer\`).
4. Run the **`CG-Viz Explorer.exe`** file.

> **⚠️ Note for Windows Users:**
> Since this app does not have an expensive digital certificate, *Windows SmartScreen* or your antivirus might display a warning during the first launch. 
> Click **"More info"** ➜ **"Run anyway"**. It is completely safe.

## 📖 Quick Start

1. **Add Library:** Click the `✚` button on the left panel (or press `Ctrl+N`) to add your asset folders.
2. **3ds Max Integration:** In the top menu, go to **"Tools"** ➜ **"Install script for 3ds Max"**. This establishes a two-way connection (click-to-add objects to your scene).
3. **Generate Cache:** For fast browsing of large libraries (HDRI, IES, etc.), use the **"⚡ Pre-caching heavy assets"** menu. The app will generate all thumbnails in the background.

## ⌨️ Shortcuts
- `Ctrl + N` — Add a new folder to the catalog.
- `F5` — Refresh the current folder.
- `Ctrl + P` — Open application settings.
- `Double Click / Spacebar` — Quick file preview (Overlay, Video, Document).
- `Alt + F4` — Exit the application.

# Українська Версія 🇺🇦

## 🌟 Про програму
**CG-Viz Explorer** — це універсальний інструмент для каталогізації, управління та використання вашої 3D-бібліотеки. Від 3D-моделей і матеріалів до скриптів і важких HDRI-карт — усе структуровано та доступно в кілька кліків.

## ✨ Основні можливості

- **📦 Миттєва каталогізація:** Зручний перегляд 3D-моделей (.max, .fbx, .obj, .blend), матеріалів, IES-світильників, текстур, відео та аудіо.
- **🔌 Глибока інтеграція з 3ds Max:** Drag-and-Drop асетів прямо у сцену, гнучкі налаштування імпорту, скрипт-зв'язок (Listener), автопризначення та рендер прев'ю для матеріалів (.mat).
- **🏷️ Розумна система тегів:** Ієрархічне дерево тегів, обрані файли (Favorites) та миттєвий глобальний пошук по базі.
- **👁️ Преміальний перегляд та плеєри:** Повноекранний перегляд HDRI/EXR з регулюванням експозиції (360°), вбудовані аудіо- та відеоплеєри з контролем швидкості.
- **🛠️ Вбудовані CG-Інструменти:**
  - Генератор безшовних текстур (з 3D-сферою для прев'ю).
  - Генератор PBR-карт (Normal, Bump, Reflect, Displace).
  - Оптимізатор та ресайзер важких текстур і HDRI.
  - Масовий конвертер форматів зображень.

## 🚀 Як встановити та запустити (.exe)

Ця програма розповсюджується у вигляді готового виконуваного `.exe` файлу (Portable). Вам не потрібно встановлювати Python або додаткові бібліотеки.

1. Перейдіть у розділ **[Releases](../../releases)** на цій сторінці GitHub.
2. Завантажте останній архів з програмою (наприклад, `CG-Viz_Explorer_v1.0.zip`).
3. Розпакуйте архів у будь-яку зручну папку (наприклад, `D:\CG-Viz Explorer\`).
4. Запустіть файл **`CG-Viz Explorer.exe`**.

> **⚠️ Примітка для користувачів Windows:**
> Оскільки програма не має дорогого цифрового підпису, *Windows SmartScreen* або ваш антивірус можуть показати попередження під час першого запуску. 
> Натисніть **«Докладніше» (More info)** ➜ **«Виконати в будь-якому випадку» (Run anyway)**. Це абсолютно безпечно.

## 📖 Швидкий старт

1. **Додавання бібліотеки:** Натисніть кнопку `✚` на лівій панелі (або `Ctrl+N`), щоб вказати ваші папки з 3D-асетами.
2. **Інтеграція з 3ds Max:** У верхньому меню перейдіть до **«Інструменти»** ➜ **«Встановити скрипт для 3ds Max»**. Після цього запрацює двосторонній зв'язок (додавання об'єктів у сцену за кліком).
3. **Генерація кешу:** Для швидкої роботи з великими бібліотеками (HDRI, IES), скористайтеся меню **«⚡ Пре-кешування важких асетів»**. Програма згенерує усі мініатюри у фоні.

## ⌨️ Гарячі клавіші
- `Ctrl + N` — Додати нову папку до каталогу.
- `F5` — Оновити вміст поточної папки.
- `Ctrl + P` — Відкрити налаштування програми.
- `Подвійний клік / Пробіл` — Швидкий перегляд файлу (Оверлей, Відео, Документ).
- `Alt + F4` — Вийти.
